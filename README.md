# Catapult Chaos

Тактическая физическая рогатка про котов-хулиганов. Вертикальный срез: пять котов с уникальными способностями, разрушаемые конструкции, TNT-цепочки, батуты, порталы, доставка сейфа, золотые рыбки и четыре демо-уровня.

**Стек:** Vite · TypeScript strict · Matter.js · Canvas 2D · Web Audio API. Спрайты и звуки не требуются: графика и аудио процедурные.

## Запуск

Требуется Node.js ≥ 20.19.

```bash
npm install
npm run dev
```

Открой адрес Vite (обычно `http://localhost:5173/`). Production-проверка:

```bash
npm run typecheck
npm run build
npm run preview
```

## Как играть

1. Выбери уровень.
2. Потяни кота мышью или пальцем от рогатки. Пунктир показывает начальный участок траектории.
3. Отпусти для запуска. Во время полёта кликни/тапни в любом месте или нажми `Space`, чтобы активировать способность.
4. Дождись стабилизации сцены — следующий кот зарядится автоматически.
5. Выполни обязательные цели. Золотая рыбка — отдельный бонус.

| Кот | Способность |
|---|---|
| Классик | Дополнительный рывок по направлению движения |
| Наковальня | Обнуляет горизонтальную скорость, тяжелеет в 6 раз и падает вниз |
| Попрыгун | Получает импульс и почти максимальную упругость |
| Матрёшка | Разделяется на четырёх котят веером |
| Магнит | 0,8 с притягивает предметы, затем отталкивает их |

### Клавиши

- `R` — рестарт;
- `C` — обзор карты / слежение;
- `M` — включить/выключить звук;
- `Esc` — пауза;
- `Space` — способность;
- `D` — физический debug overlay;
- перетаскивание свободной области — движение камеры.

Прогресс (звёзды, лучший счёт, рыбки) сохраняется в `localStorage` через `IStorageAdapter`. Это позволяет позднее заменить хранилище на Yandex Games SDK без изменения игровой логики.

## Уровни

1. **Большой кухонный бум** — стекло, дерево, враги и цепная реакция TNT.
2. **Крепость под прессом** — батут, высокая стена, каменная крыша, Наковальня и Попрыгун.
3. **Четвёртый ход** — связанные порталы, укрепления, Матрёшка и Магнит.
4. **Операция «Сейф»** — доставить хрупкий сейф в зону удержания, по пути можно собрать рыбку.
