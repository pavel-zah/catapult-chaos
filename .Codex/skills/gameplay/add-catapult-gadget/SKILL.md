# Добавление гаджета

Прочитай `ARCHITECTURE.md`, `src/entities/types.ts`, `src/entities/GadgetRegistry.ts`и два похожих гаджета.

## Процесс

1. Добавь literal-тип в `GadgetSpawnConfig.type` и при необходимости только нужные декларативные поля.
2. Создай `src/entities/gadgets/<Name>.ts` с `GadgetFactory`.
3. Каждому Matter-телу задай `kind: 'gadget'`, стабильный `entityId: spawn.id`, бесконечные HP/threshold для неразрушаемого гаджета.
4. Верни `GadgetInstance`. Связь с другими объектами ищи через `getGadget` в момент события, а не во время создания: порядок spawn может быть любым.
5. Зарегистрируй фабрику в `gadgets/index.ts` и размести на уровне.
6. Изменяй скорости через `PhysicsWorld`, визуализируй через `render`, не добавляй отдельный DOM.

## Критичные края

- Повторные `collisionStart` не должны дублировать награду/импульс.
- Телепорты нуждаются в per-body cooldown и безопасной точке выхода.
- Сенсор не наносит обычный урон столкновением.
- Продолжительные таймеры не используют `setTimeout`.
- Рестарт уровня не должен сохранять состояние предыдущего экземпляра.

## Проверка

Проверь кота, блок и целевой объект, прямое и обратное взаимодействие, рестарт, pause. Выполни `npm run typecheck` и `npm run build`.
