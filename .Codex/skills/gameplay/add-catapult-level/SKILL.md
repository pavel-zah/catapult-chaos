# Создание уровня

Прочитай `src/levels/schema.ts`, `ARCHITECTURE.md` и ближайший по механике уровень. Не меняй ядро, если контент можно описать существующей схемой.

## Процесс

1. Создай `src/levels/levelNN.ts` и заполни `LevelData` с уникальным `id` уровня и каждой сущности.
2. Используй мир 1920×1080, углы в градусах и стандартный пол `y: 1020`, `height: 80`, если уровню не нужно иное.
3. Составь очередь так, чтобы обязательная механика была выполнима хотя бы двумя разумными способами.
4. Для `deliver_to_zone` трижды сверь связь `targetId`: цель уровня, gadget и target spawn. Для порталов укажи взаимные `pairId`.
5. `bonus_fish` — необязательная цель. Не делай её обязательной для победы.
6. Пороги двух/трёх звёзд задай после ручных прохождений, не случайными числами.
7. Добавь уровень в `LEVELS` в `src/levels/index.ts`.

## Ручная приёмка

- Первые 400 мс конструкция не разрушается сама.
- Есть понятные победа и поражение, следующий кот выдаётся после стабилизации/таймаута.
- Рыбка сохраняется, звёзды и лучший счёт не уменьшаются при повторном прохождении.
- Доставка засчитывается только после 0,8 с удержания; разрушенный сейф означает поражение.
- Камера показывает рогатку и важные цели, уровень играбелен мышью и тачем.
- Выполни `npm run typecheck` и `npm run build`.
