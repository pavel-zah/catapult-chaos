# Правила для AI-агента

Этот проект — учебная работа студента. Помогай писать код, но не забирай у студента контроль над проектом.

## Главное правило

**Делай минимальное изменение, которое решает поставленную задачу.**

Не переписывай проект целиком без прямого запроса.

## Перед изменением

1. Кратко сформулируй, что собираешься изменить.
2. Укажи файлы, которые потребуется тронуть.
3. Если задача неоднозначна, выбери самое простое решение, соответствующее текущей архитектуре.

## Во время изменения

- сохраняй TypeScript strict;
- не добавляй библиотеку, если задачу легко решить без неё;
- не создавай новые уровни абстракции "на будущее";
- не меняй несвязанные файлы;
- выноси важные игровые параметры в понятные константы;
- предпочитай маленькие функции;
- не удаляй рабочую механику без явного требования;
- не добавляй backend, базу данных или сетевую часть без явной необходимости.

## После изменения

Сообщи:

1. какие файлы изменены;
2. что именно изменилось;
3. как проверить результат вручную;
4. какие риски или ограничения остались.

Если возможно, предложи выполнить:

```bash
npm run typecheck
npm run build
```

## Запрещено

- генерировать полностью новую игру вместо изменения существующей;
- молча менять архитектуру всего проекта;
- прятать важную игровую логику в магических числах;
- добавлять платные сервисы;
- добавлять зависимость только ради нескольких строк кода.

## Текущая архитектура Catapult Chaos

Стек проекта: **Vite + TypeScript strict + Matter.js + Canvas 2D**. Phaser больше не используется. Точка сборки всех систем — `src/Game.ts`; декларативный контент — `src/levels/`.

- Сначала читай `ARCHITECTURE.md`: там карта модулей, физические инварианты и рецепты расширения.
- Новых котов добавляй через отдельный `CatDefinition` и `CatRegistry`, материалы — через `BlockRegistry`, гаджеты — через `GadgetRegistry`.
- Не добавляй `switch` по типам сущностей в `LevelLoader`.
- Общие настройки находятся в `src/constants.ts`; специфичные параметры кота/блока — в его определении.
- Не используй `setTimeout` для gameplay: только scheduler игрового времени в `Game`.
- Новые Matter-тела получают метаданные через `attachMetadata`; скорости ограничиваются `PhysicsWorld`.
- Для добавления кота/гаджета/уровня применяй соответствующий skill из `.Codex/skills/gameplay/`.

Перед завершением обязательны `npm run typecheck` и `npm run build`, а для игровых механик — ручная проверка хотя бы одного полного хода.

## Каталог доступных механик и гаджетов

Полные числовые значения по умолчанию и рецепты комбинирования находятся в `ARCHITECTURE.md`. Все гаджеты регистрируются в `src/entities/gadgets/index.ts`, конфиги образуют discriminated union `GadgetSpawnConfig` в `src/levels/schema.ts`.

| `type` | Основные параметры | Канал и особенности |
|---|---|---|
| `trampoline` | `width`, `height`, `angle` | Канала нет; импульс по нормали батута. |
| `portal` | `pairId`, `width`, `height`, `angle` | Канала нет; парный телепорт с cooldown. |
| `goal_zone` | `targetId`, `width`, `height`, `angle` | Канала нет; доставка сейфа с удержанием 0,8 с. |
| `bonus_fish` | `radius` | Канала нет; одноразовый бонус. |
| `button` | `channelId`, `mode`, `impulseThreshold`, `width`, `height` | Триггер `once/toggle`, активируется только ударом выше порога. |
| `pressure_plate` | `channelId`, `minMass`, `width`, `height` | Триггер, активен лишь при достаточной суммарной массе на сенсоре. |
| `door` | `channelId`, `invertSignal`, `openOffset`, `moveSpeed`, размеры/`angle` | Плавная раздвижная преграда, без канала закрыта, при потере сигнала закрывается. |
| `trapdoor` | `channelId`, `invertSignal`, `hinge`, `material`, размеры/`angle` | Одно разблокирование шарнирной балки, без канала закрыт, автоматически не закрывается. |
| `fan` | `channelId`, `invertSignal`, `strength`, размеры/`angle` | Постоянная сила внутри сенсора; тяжёлые тела сопротивляются сильнее, без канала включён. |
| `gravity_zone` | `channelId`, `invertSignal`, `gravityScale`, размеры | Компенсация мировой гравитации + собственная, демпфирование; без канала включена, зоны не перекрывать. |
| `seesaw` | размеры, `angle`, `pivotOffset`, `maxTilt` | Динамическая доска на шарнире с ограничением угла, канала нет. |
| `rope` | `anchor`, `targetBlockId` или `cargo`, размеры груза | Constraint разрывается котом или лазером; встроенный груз `stone/tnt/treasure_box`. |
| `laser` | `channelId`, `invertSignal`, `angle`, `maxLength` | Ближайшее плотное тело блокирует луч; стекло пропускает его, TNT взрывается через 150 мс, rope/vacuum разрезается/уничтожается. |

Каналы объединяют несколько триггеров по **OR**. `invertSignal` работает у приёмника только с заданным `channelId`. Индикаторы цвета канала обязательны, связи показываются при старте и по `D`. Все состояния каналов очищает `ChannelSystem.reset()` при загрузке/рестарте уровня. Лазерные эффекты и разрыв верёвки идут через `EventBus`, TNT задерживается только игровым scheduler.

Проверять новые комбинации нужно в отдельной `sandbox-gadgets`, доступной по кнопке меню. Основные уровни 1–4 и их проходимость нельзя менять ради тестирования гаджетов.

## Контекст курса

Проект должен оставаться:

- индивидуальным;
- браузерным;
- небольшим;
- запускаемым на слабом компьютере;
- пригодным для последующей публикации и сбора игровых метрик.
